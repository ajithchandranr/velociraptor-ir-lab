# velociraptor-ir-lab
A hands-on Velociraptor DFIR lab built from scratch - covering server deployment, endpoint enrollment, forensic artifact collection, and detection engineering across multiple phases.

This repo documents a Velociraptor incident response lab built from the ground up on VirtualBox. Each phase covers a real investigative capability - not just how to run the tool, but why each artifact matters during an active engagement.

Built by a SOC analyst working in 24/7 MSSP operations. The scenarios and techniques here come directly from real IR work, not textbook examples.

Phases:

Phase 1 - Server deployment, endpoint enrollment, baseline triage collection

Phase 2 - MFT collection and timeline building (coming)

Phase 3 - Simulated compromise and detection (coming)
